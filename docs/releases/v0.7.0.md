# Archcodex 0.7.0 — Configurable keyboard navigation

Development release for Linux host testing.

## Changes

- Add a command palette and shared application shortcuts that work while the embedded terminal has focus.
- Add Keyboard Shortcuts settings with conflict validation, Apply/Cancel, saved bindings and Restore Defaults.
- Change Ctrl+Tab into a chooser that activates only on Ctrl release; Shift reverses direction and Escape cancels.
- Add Ctrl+backtick project cycling for projects with open terminals, selecting the most recently activated terminal in each project.
- Add keyboard access to Projects tabs, pane focus, context menus and terminal scrollback search. Existing explorer ordering is unchanged.

## Default shortcuts

| Shortcut | Action |
| --- | --- |
| Ctrl+Shift+P | Command palette |
| Ctrl+Shift+F | Search terminal scrollback |
| Ctrl+Alt+P / Ctrl+Alt+F | Focus Projects / its search or filter field |
| Alt+1–5 | All / Active / Running / Waiting / Opened |
| Alt+0 | Return to the terminal |
| F6 / Shift+F6 | Switch pane |
| Ctrl+Tab / Ctrl+Shift+Tab | Cycle recent terminals; release Ctrl to activate |
| Ctrl+backtick / Ctrl+Shift+backtick | Cycle projects with open terminals |
| Ctrl+Shift+, | Settings |

## Install

Download `Archcodex-0.7.0-x86_64.flatpak` and `SHA256SUMS` from this release into the same directory. Quit an older Archcodex instance, then run these commands in the **local host terminal**, outside myCodex or another container:

```sh
sha256sum -c SHA256SUMS
flatpak install --user --or-update ./Archcodex-0.7.0-x86_64.flatpak
flatpak run io.github.emsi.Archcodex
```

The bundle targets **x86_64 Linux**, uses X11/XWayland and KDE Platform 6.11, and declares Flathub as the runtime source. A compatible host Codex CLI and an independently running app-server are required; Codex 0.166.0 was used for protocol validation. Archcodex does not install Codex.

myCodex integration requires Docker access and Python 3 on the selected hosts. Remote hosts need an accepted SSH host key and non-interactive SSH authentication.

myCodex TUIs require **Codex 0.166.0 or newer on the local computer** and a running **systemd user manager** for transport supervision. Tools and workspaces remain in the selected container.

## Validation and source

This is the original historical bundle, not a rebuild. Before publication it was imported into an isolated OSTree repository, its packaged executable and AppStream version were checked, and its SHA-256 was recorded. The build environment cannot run a complete Flatpak sandbox because user namespaces are restricted; full desktop acceptance is not implied by these checks.
