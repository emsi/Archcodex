# Archcodex 0.1.0 — Initial native Linux workspace

Development release for Linux host testing. Historical version; use the [latest release](https://github.com/emsi/Archcodex/releases/latest) for normal installation.

## Changes

- Connect to multiple existing local Unix-socket Codex app-servers from a native Qt/KDE interface.
- Group conversations by working directory, browse All/Active views, and search conversation text across connected servers.
- Use the existing Codex TUI inside an embedded Konsole terminal; session indicators follow server events without status polling.
- Add projects and connection profiles manually, with metadata and recent-use information retained locally.

## Version-specific notes

This initial version requires manual connection/project setup. Automatic discovery arrives in 0.2.0; the richer live-session classification and retained terminal output arrive in 0.2.1.

## Install

Download `Archcodex-0.1.0-x86_64.flatpak` and `SHA256SUMS` from this release into the same directory. Quit an older Archcodex instance, then run these commands in the **local host terminal**, outside myCodex or another container:

```sh
sha256sum -c SHA256SUMS
flatpak install --user --or-update ./Archcodex-0.1.0-x86_64.flatpak
flatpak run io.github.emsi.Archcodex
```

The bundle targets **x86_64 Linux**, uses X11/XWayland and KDE Platform 6.11, and declares Flathub as the runtime source. A compatible host Codex CLI and an independently running app-server are required; Codex 0.166.0 was used for protocol validation. Archcodex does not install Codex.

## Validation and source

This is the original historical bundle, not a rebuild. Before publication it was imported into an isolated OSTree repository, its packaged executable and AppStream version were checked, and its SHA-256 was recorded. The build environment cannot run a complete Flatpak sandbox because user namespaces are restricted; full desktop acceptance is not implied by these checks.
