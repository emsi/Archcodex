# Archcodex 0.8.1 — Fix New-session identity and rename tracking

Development release for Linux host testing. Fixes [#4](https://github.com/emsi/Archcodex/issues/4): a working terminal created with **New** could remain labelled **New session terminal**, ignore `/rename` in Projects, and miss Running/Waiting updates.

## Changes

- Create the conversation on the selected server and open its exact returned ID. Rename, status, filtering and restoration now update the same session record.
- Initially save the title **New session** so even an empty conversation can be resumed by the TUI. Use `/rename` to change it. The selected server's configuration and clicked working directory apply.
- Correlate concurrent creations without guessing from titles, directories or global events. Never automatically repeat creation after a timeout or disconnection; partial-failure diagnostics retain the known ID.
- Preserve older unresolved terminal views while preventing their launcher from accidentally creating another conversation.

## Known limitations and compatibility

Switching conversations inside the TUI with `/new`, `/resume`, `/fork` or agent navigation can still leave the original launch target saved. Open the intended conversation from Projects for an unambiguous restore target. Older unresolved **New session terminal** views cannot have their IDs inferred; open their saved conversations from Projects.

No new proxy, polling, dependency or transport process is introduced. KDE 6.11, Konsole 26.04.3, Flatpak permissions and database schema 2 are unchanged from 0.8.0. Upgrading from 0.7.1 or earlier retains the [schema-2 backup/downgrade requirements](https://github.com/emsi/Archcodex/blob/v0.8.1/docs/workspace.md#persistence-and-compatibility).

## Install or update

Download `Archcodex-0.8.1-x86_64.flatpak` and `SHA256SUMS` from this release into the same directory. Quit Archcodex, then run in your **local host terminal**, outside myCodex or another container:

```sh
sha256sum -c SHA256SUMS
flatpak install --user --or-update ./Archcodex-0.8.1-x86_64.flatpak
flatpak run io.github.emsi.Archcodex
```

The bundle targets **x86_64 Linux with X11/XWayland**. Existing local Codex, app-server, Docker/Python, SSH and systemd-user requirements are unchanged.

## Verification and source

This release publishes the previously built and tested Flatpak unchanged; no GitHub build was run. All nine recorded suites pass, including 23 X11 window cases, 17 terminal cases and 28 model cases. An isolated stock Codex 0.166.0/real-PTY probe verified creation, attachment and rename on one ID without another TUI creation request. Packaged window/Konsole smoke testing and isolated installation passed.

Full Flatpak sandbox execution and actual desktop/SSH/container acceptance remain unverified in the build container because it prohibits user namespaces. Uploaded assets are downloaded and checked against the original bundle before publication.
