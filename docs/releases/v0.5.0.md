# Archcodex 0.5.0 — Host groups and the Opened view

Development release for Linux host testing. Historical version; use the [latest release](https://github.com/emsi/Archcodex/releases/latest) for normal installation.

## Changes

- Organize Projects under separate local-computer, local-myCodex and remote-host groups, with shorter child labels.
- Add Opened for every open terminal view, including retained exited/error output regardless of history visibility settings.
- Add Ctrl+Tab and Ctrl+Shift+Tab navigation among recently activated open terminals.
- Allow group-scoped search while keeping backend and conversation identities separate.

## Version-specific notes

Ctrl+Tab switches the displayed terminal while cycling in this version; deferred activation arrives in 0.7.0. The myCodex TUI still runs inside the container.

## Install

Download `Archcodex-0.5.0-x86_64.flatpak` and `SHA256SUMS` from this release into the same directory. Quit an older Archcodex instance, then run these commands in the **local host terminal**, outside myCodex or another container:

```sh
sha256sum -c SHA256SUMS
flatpak install --user --or-update ./Archcodex-0.5.0-x86_64.flatpak
flatpak run io.github.emsi.Archcodex
```

The bundle targets **x86_64 Linux**, uses X11/XWayland and KDE Platform 6.11, and declares Flathub as the runtime source. A compatible host Codex CLI and an independently running app-server are required; Codex 0.166.0 was used for protocol validation. Archcodex does not install Codex.

myCodex integration requires Docker access and Python 3 on the selected hosts. Remote hosts need an accepted SSH host key and non-interactive SSH authentication.

## Validation and source

This is the original historical bundle, not a rebuild. Before publication it was imported into an isolated OSTree repository, its packaged executable and AppStream version were checked, and its SHA-256 was recorded. The build environment cannot run a complete Flatpak sandbox because user namespaces are restricted; full desktop acceptance is not implied by these checks.
