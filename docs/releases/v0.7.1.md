# Archcodex 0.7.1 — Restore terminal scrollback shortcuts

Development release for Linux host testing. Includes
[fa62908](https://github.com/emsi/Archcodex/commit/fa62908a109fc6d5e5963c0d61fd84641df031a3).

## Changes

- Restore Shift+Page Up/Down and Shift+Home/End for scrolling terminal history
  when a client requests the enhanced keyboard protocol.
- Bundle **Konsole 26.04.3** in place of 26.08.2 to avoid
  [KDE bug 524571](https://bugs.kde.org/show_bug.cgi?id=524571). This pin uses
  legacy keyboard handling; it does not enable the enhanced keyboard protocol.
- Add real-terminal regression coverage for legacy clients and clients requesting
  enhanced keyboard handling, including checks that scroll keys do not reach
  the child process.
- Include the reorganized README with installation first, followed by features,
  usage and developer instructions.

The KDE 6.11 runtime, existing Konsole embedding patches and Flatpak permissions
are unchanged. The installed application reports 0.7.1; the release version
metadata is a follow-up to the requested fix commit.

## Install or update

Download `Archcodex-0.7.1-x86_64.flatpak` and `SHA256SUMS` from this release into
the same directory. Quit any older Archcodex instance, then run these commands
in the **local host terminal**, outside myCodex or another container:

```sh
sha256sum -c SHA256SUMS
flatpak install --user --or-update ./Archcodex-0.7.1-x86_64.flatpak
flatpak run io.github.emsi.Archcodex
```

The bundle targets **x86_64 Linux**, uses X11/XWayland and declares Flathub as
the KDE runtime source. Archcodex requires a compatible local Codex CLI and an
independently running app-server; it does not install Codex or start app-servers.
myCodex TUIs require **Codex 0.166.0 or newer on the local computer** and a
running systemd user manager. Docker access and Python 3 are required on selected
myCodex hosts; remote hosts need accepted SSH host keys and non-interactive
authentication.

## Source and compatibility

All eight test suites pass across the native, KDE SDK and X11 environments,
including 15 real-terminal cases and 21 X11 window cases. The scrollback tests
cover legacy and enhanced-keyboard requests. The stripped package reports
Archcodex 0.7.1 and Konsole 26.04.3 and passes its window/Konsole smoke test.
Full Flatpak sandbox launch still requires desktop
acceptance: the build container prohibits user namespaces. This release retains
the existing feature scope and connection requirements.
